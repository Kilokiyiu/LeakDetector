# 从读方法升级到拆产品架构

用户已能跟对象传递，并对 `ParseLine` 有运行层了解；下一步目标是：不仅知道方法怎么跑，还要能从方法抽出设计决策，并迁移到「新产品如何切阶段、定契约、落地业务」。后续教学默认用三层（运行 / 决策 / 产品）+ 方法五道决策题 + 产品五步梯子；不以读完 API 手册当「详细学习」。

## Implications

- `ParseLine` 复习改问边界/契约/形状/失败/替换，不重复讲 DOM 语法
- 后期系统内存观测课：先逼用户画阶段与契约，再引入平台 API
