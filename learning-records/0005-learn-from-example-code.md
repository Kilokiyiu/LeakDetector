# 示例代码没亲手写过时的高效学法

用户明确提出：老师给的示例里有很多自己没写过的代码，不知道具体作用，想最大化学习效率。后续教学默认采用「五步循环」：钉目标 → 输入/输出（可黑盒）→ 一条真数据 → 预测再跑 → 人话一句；陌生 API 只在目标需要或预测失败时再开窗。提问时优先要用户说出半句当前理解。

## Implications

- 讲新代码时先给输入/输出与一条可跑数据，再展开 API 细节
- 不要求用户第一次见面就背完整实现；用「合上重写签名」做存储练习
