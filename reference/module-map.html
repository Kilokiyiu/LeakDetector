模块地图

按「输入 → 输出 → 绝不做」记边界。类名与调用顺序以源码为准。

架构与原理 怎么运行 JSONL 与解析 C# 分析

总表

模块输入输出绝不做
include/ (C++) 被测程序的 new/delete 内存表 + 控制台报告 + 可选 JSONL 复杂报告排版、单元测试框架
Core MemoryEvent 序列 AnalysisReport 读文件、写控制台、解析 JSON
Parsers .jsonl 路径 事件列表 判断有没有泄漏
Analyzers 日志路径 AnalysisReport 重新发明配对算法（委托 Core）
Reporters AnalysisReport 人类可读文本 读 JSON、算泄漏
CLI 命令行参数 退出码 + 控制台输出 塞业务算法
Tests 固定事件 / 样例文件 断言结果 依赖本机绝对路径

Core 模型（架构角色）

  • 事件：分配 / 释放 / 摘要
  • 报告：泄漏条目 + 未知 free 等统计
  • 分析器：按事件顺序维护 live 集合；忽略摘要事件

类型与方法名见 src/LeakDetector.Core。

管线职责链

CLI：参数与退出码
↓
Analyzers：打开路径，串联翻译与判断
↓
Parsers：行 → 事件（不判泄漏）
↓
Core：配对 → 报告
↓
Reporters：只展示
