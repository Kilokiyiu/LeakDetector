怎么运行

最短演示路径：用现成 JSONL 跑 CLI；需要完整链路时再跑 C++ example。

架构 模块地图 CLI 契约 学习入口

A. 只跑 C#（推荐复习）

dotnet test LeakDetector.sln

dotnet run --project src/LeakDetector.CLI -- analyze testdata/sample_events.jsonl
# 期望退出码 1（确定泄漏）

dotnet run --project src/LeakDetector.CLI -- analyze testdata/sample_no_leak.jsonl
# 期望退出码 0

样例：testdata/sample_events.jsonl、testdata/sample_no_leak.jsonl。

B. 跑 C++ example（产生自己的日志）

以 examples/simple_leak 为例：只分配不释放，结束时扫表报告。

$env:LEAK_DETECTOR_MODE = "both"
$env:LEAK_DETECTOR_LOG_PATH = ".\leak_log.jsonl"
# 在 example 目录构建并运行可执行文件
  • 控制台：泄漏报告
  • 文件：至少含 alloc 与 summary 行

仓库中也可能已有 example 产出的 leak_log.jsonl，可直接喂给 CLI。

推荐 5 分钟演示

  1. 打开样例 JSONL，指三种事件字段
  2. 跑有泄漏 / 无泄漏两条 CLI，对照退出码
  3. 口头走一遍 live 配对（见 C# 分析）
