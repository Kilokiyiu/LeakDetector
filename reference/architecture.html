模块地图 JSONL 与解析 C# 分析 怎么运行

一句话

在 C++ 进程内盯住 new/delete 并记账； 可选写出 JSONL，由 C# 管线翻译并再配对，报告「分配了却未释放」的块。

为什么两段式

  • C++ 侧必须与被测程序同进程，才能拦截分配。
  • C# 侧承担解析、分析、测试与 CLI，不与每个 example 强链接。
  • 中间用 JSONL 文件作稳定契约：一边写、一边读。
被测 C++：new / delete
↓ 插桩记账（可选写 JSONL）
契约文件：alloc / free / summary 行
↓
C#：翻译 → 判断 → 展示 → CLI 退出码

核心架构思想

档案卡

分配建卡、释放销卡、结束扫表。表中剩余即确定泄漏。 与 Valgrind 类工具的「chunk 账本」同族；本项目是教学向轻量实现（无红区/影子内存）。 对照笔记：docs/mc_include.md。

拦截如何带上位置信息

通过宏把 new 展开为带文件名/行号的形式，再进入重载的分配函数。 展开与 #undef 细节见 include/leak_detector.*； 背景阅读 Microsoft Learn: new operator。

C# 再算一遍

不读 C++ 进程内表。解析 JSONL 为事件后，用同一套「live 字典」算法配对。 summary 行不参与裁判。算法速查： C# 分析。
