CLI 契约

命令字与退出码的稳定含义。实现： src/LeakDetector.CLI/Program.cs。

怎么运行 模块地图 范围与约束

用法

LeakDetector.CLI analyze <path-to.jsonl>

退出码

码含义
0分析成功且无泄漏
1分析成功但发现泄漏（CI 可当失败）
2文件不存在
3用法错误
4未预期异常
退出码 1 表示账本配对后的确定泄漏，不是曲线推断的「疑似」。

演示

dotnet run --project src/LeakDetector.CLI -- analyze testdata/sample_events.jsonl
报告文本格式见 Reporters 源码；本文只固定门面契约。
