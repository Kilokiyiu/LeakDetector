架构 模块地图 JSONL CLI 契约

交接边界

侧手里有什么交给对面
C++ 进程内分配表 + 可选控制台报告 .jsonl
C# 文件路径 分析报告 → 文本 + 退出码

两边不共享进程内表。C# 用日志把账本重算一遍。

职责链

CLI：路径与退出码
↓
Analyzers：串联翻译与判断
↓
Parsers：行 → 事件
↓
Core：配对 → 报告
↓
Reporters：展示

配对算法

live = 空集合
foreach 事件（按序）:
  alloc → 放入 live
  free  → 从 live 删除；删不到则未知 free++
  summary → 忽略
确定泄漏 = live 里剩下的

与 C++ 扫表同构、不同舞台。实现：src/LeakDetector.Core/。

样例

文件序列结论
sample_events.jsonl alloc → summary 1 条确定泄漏
sample_no_leak.jsonl alloc → free → summary 0

谁信谁

  • 裁判：C# live 扫完的结果
  • 旁证：JSONL 的 summary（解析保留，分析忽略）
  • C++ 控制台：进程内当时扫表；应与 C# 一致，但是另一舞台

别越界

  • Parsers 不说有没有泄漏
  • Core 不读文件、不打印
  • Analyzers 不重写配对
  • Reporters 不解析 JSON
