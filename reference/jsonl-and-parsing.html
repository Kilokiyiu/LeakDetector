JSONL 契约

现行字段与翻译边界。写出/读入实现见 include/leak_detector.cpp、 JsonlEventParser。 短课：0004。

架构 怎么运行 C# 分析

格式

按 jsonlines.org：UTF-8； 每一行一个完整 JSON 值；用换行分隔。适合追加写日志。 

{"event":"alloc", ...}
{"event":"free", ...}
{"event":"summary", ...}

事件契约

公共字段：event（类型）、id（序号）。

alloc

字段含义
event"alloc"
id事件序号
ptr指针字符串
size字节数
kindnew 或 new[]
file / line分配点位置

free

字段含义
event"free"
id序号
ptr释放的指针
kinddelete / delete[]

summary

字段含义
event"summary"
id序号
leak_countC++ 扫表得到的泄漏个数
total_leak_bytes泄漏总字节
C# 分析器不依赖 summary 下结论；凭 alloc/free 自算。summary 是 C++ 侧快照，便于对照。

翻译边界

  • 输入：文件路径或一行字符串
  • 输出：有序事件列表（分配 / 释放 / 摘要）
  • 绝不：判断泄漏、写报告
  • 失败：缺字段 / 未知 event → 抛错（早暴露）

现行实现用手写 JSON DOM 按 event 分支建强类型事件 （背景： Use a JSON DOM）。 逐步 API 调用打开 Parsers 源码。

样例结论

  • sample_no_leak.jsonl：alloc → free → summary → 泄漏 0
  • sample_events.jsonl：alloc → summary → 泄漏 1
