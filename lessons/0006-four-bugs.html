Lesson 0006

门面契约诊断

练：读症状 → 定位层（CLI / Reporter / Tests）→ 对照现行契约。 契约正文：CLI 契约。

现行门面（先记对的）

LeakDetector.CLI analyze <path-to.jsonl>

0  分析成功且无泄漏
1  分析成功但发现泄漏
2  文件不存在
3  用法错误
4  未预期异常

退出码约定依据： Environment.Exit （0 = 成功完成目标；非零 = 需脚本关注的情况）。

若出现这些症状，该查哪一层？

症状优先怀疑对照决策
按帮助敲命令立刻 Usage 错误 CLI Usage 文案与判断的子命令必须同一词
有泄漏时退出码仍是 0 CLI 有泄漏应返回非 0（现行为 1）
泄漏行打出 {leak.Size} 字面量 Reporter 插值字符串需正确求值字段
测试找不到 testdata Tests 从输出目录回仓库根的路径必须够层数（或改复制夹具）

用现行契约自检（约 5 分钟）

  1. dotnet run --project src/LeakDetector.CLI -- analyze testdata/sample_events.jsonl → 期望退出码 1，泄漏行是数字不是花括号
  2. 再跑 testdata/sample_no_leak.jsonl → 期望退出码 0
  3. 故意少参数或错子命令 → 期望退出码 3
  4. dotnet test → 解析/分析测试通过
