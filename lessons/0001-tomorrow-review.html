复习路线

目标：能自己把项目讲顺。先读 reference（架构），再用短课自测。 总入口：学习入口。

建议节奏（约 45–60 分钟）

  1. 全景 — 架构 → 短课自测
  2. 怎么跑 — 怎么运行； 用 testdata 跑一次 CLI
  3. 契约 — JSONL → 短课
  4. 模块与交接 — 模块地图、 C# 分析； 课 0003 / 0005 / 0008
  5. 门面契约 — CLI 契约 → 诊断练习
  6. 范围 — 范围与约束 → 短课
  7. 怎么学更深 — 0009、 0010
验收（对照 MISSION）： 能说出流水线阶段；能说明档案卡如何变成泄漏报告；能分清 Parsers 与 Analyzer。
