# v0.2 加固指南（人话版）

> **这篇在说什么？**  
> 管线已经能跑了。加固不是加新功能，而是：**用自动测试把「以前犯过的错」钉死**，免得改代码时又踩回去。  
>
> **你读完要能回答：** 我接下来要写哪几份测试？为什么要拆一个 `CliApp`？testdata 为什么要复制到 bin？

关联：[怎么搭管线](v0.2-implementation-guide.md) · [下一步做什么](dev-roadmap.md) · [退出码约定](../reference/cli-contract.html)

---

## 0. 先别看细节：加固只干三件事

| # | 人话 | 技术说法 | 做完长什么样 |
|---|------|----------|--------------|
| 1 | **报告别再打出花括号字面量** | 给 `ConsoleReporter` 写测试 | 测「有泄漏 / 无泄漏」两段文字对不对 |
| 2 | **退出码别再靠人记** | 把 CLI 逻辑抽出来写测试 | 无泄漏→0，有泄漏→1，用法错→3，文件没有→2 |
| 3 | **测试找样例文件别再数 `..`** | 构建时把 `testdata` 拷到输出目录 | 路径写成 `AppContext.BaseDirectory + testdata/...` |

做完这三件，在仓库根执行：

```powershell
dotnet test LeakDetector.sln
```

全绿，加固就过关。

**本篇不做：** 图形界面、系统内存观测、GitHub Actions、新的 C++ 示例。

---

## 1. 为什么要加固？（对照你踩过的坑）

以前出过这类问题：

- 退出码写反 / 子命令写成 `analyzer`
- 报告字符串漏了 `$`，屏幕上出现 `{leak.Size}` 这种字面量
- 单元测试用一串 `".." , ".."` 往上爬找 `testdata`，换机器或换输出路径就脆

功能「能跑」和「改完还敢跑」不是一回事。加固 = **用测试当保险丝**。

---

## 2. 退出码约定（测试就按这个写）

命令形状：

```text
LeakDetector.CLI analyze <某个.jsonl路径>
```

| 退出码 | 含义 |
|--------|------|
| 0 | 分析成功，**没有**泄漏 |
| 1 | 分析成功，**发现了**泄漏 |
| 2 | 文件不存在 |
| 3 | 用法不对（参数不够 / 不是 `analyze`） |
| 4 | 其它异常 |

`analyze` 大小写无所谓。

报告文字（和现在的 `ConsoleReporter` 对齐）：

- 无泄漏：`[LeakDetector] No leaks detected`
- 有泄漏：必须出现真实数字和路径，例如 `LEAK: 4 bytes at 0x1  [main.cpp:7]`  
  **绝不能**再出现 `{leak.Size}` 这种没求值的花括号。

### 第 1 步：给「报告文字」写测试（最小、最容易）

**要改 / 新建的文件：**

- `src/LeakDetector.Tests/LeakDetector.Tests.csproj` — 加上对 Reporters 的项目引用
- `src/LeakDetector.Tests/ConsoleReporterTests.cs` — 新建（文末有可抄模板）

**怎么验收：**

```powershell
dotnet test LeakDetector.sln --filter ConsoleReporterTests
```

### 第 2 步：给「退出码」写测试（需要先拆一层）

**卡点（人话）：**  
现在逻辑都塞在 `Program.Main` 里。`Main` 不好测：它绑着真实磁盘、真实分析。  
所以先把「看参数、定退出码」挪到一个叫 `CliApp` 的类里；测试时塞一个**假的分析函数**（不读真实 JSONL，直接返回「0 条泄漏」或「1 条泄漏」的报告）。

**关系图：**

```text
真正运行时：
  Program.Main
    → CliApp.Run(参数, 真·分析函数, 控制台)

跑单元测试时：
  CliAppTests
    → CliApp.Run(参数, 假·分析函数, 丢弃输出)
```

**要改 / 新建：**

- `src/LeakDetector.CLI/CliApp.cs` — 新建（文末模板）
- `src/LeakDetector.CLI/Program.cs` — 改成一行转发
- Tests 项目引用 CLI
- `src/LeakDetector.Tests/CliAppTests.cs` — 新建

**至少覆盖：**

| 场景 | 期望退出码 |
|------|------------|
| 写成 `analyzer` 之类 | 3 |
| 文件根本不存在 | 2 |
| 假报告：0 泄漏 | 0 |
| 假报告：1 泄漏 | 1 |

**怎么验收：**

```powershell
dotnet test LeakDetector.sln --filter CliAppTests
```

---

### 第 3 步：让测试找到样例文件不再脆

**卡点（人话）：**  
测试跑起来时，工作目录在 `bin\Debug\...` 下面，不在仓库根。  
以前用很多个 `".."` 往上爬，层数一变就炸。

**做法：**  
在 Tests 的 `.csproj` 里声明：构建时把仓库根的 `testdata\*.jsonl` **复制到输出目录**。  
测试里只写：

```csharp
var path = Path.Combine(AppContext.BaseDirectory, "testdata", "sample_events.jsonl");
```

**要改：**

- `LeakDetector.Tests.csproj`（复制规则 + 项目引用，文末有完整示例）
- `JsonlEventParserTests.cs`（删掉所有 `".."` 爬路径）

**怎么验收：**

```powershell
dotnet test LeakDetector.sln --filter JsonlEventParserTests
# 也可在 bin\Debug\net*\testdata\ 下确认文件真的被拷过去了
```

## 5. 常见卡住点

| 你看到的现象 | 怎么想 |
|--------------|--------|
| Tests 引用不了 CLI | CLI 虽是可执行项目，仍可被 `ProjectReference`；确认 csproj 写了、再 `dotnet restore` |
| 退出码测试一跑就去读真文件、很脆 | 假分析函数只返回内存里的报告；只有「文件不存在」那条才碰路径 |
| Copy 了还是 FileNotFound | 打开 `bin\Debug\...\testdata\` 看文件在不在；`Link` 要写成 `testdata\文件名` |
| 断言失败只差一个句号 | 以**当前** `ConsoleReporter` 实际输出为准改测试字符串 |

## 6. 可复制代码（做完自己跑 test，别盲信）

命名空间以仓库现有为准（`LeakDetector.Core.Model` 等）。

### 6.1 `ConsoleReporterTests.cs`

```csharp
using LeakDetector.Core.Model;
using LeakDetector.Reporters;

namespace LeakDetector.Tests;

public class ConsoleReporterTests
{
    [Fact]
    public void Format_NoLeaks_PrintsNoLeaksLine()
    {
        var report = new AnalysisReport(Array.Empty<LeakEntry>(), UnknownFreeCount: 0);

        var text = new ConsoleReporter().Format(report);

        Assert.Contains("No leaks detected", text);
        Assert.DoesNotContain("LEAK:", text);
    }

    [Fact]
    public void Format_OneLeak_InterpolatesFields()
    {
        var report = new AnalysisReport(
            new[]
            {
                new LeakEntry("0x1", 4, "main.cpp", 7, IsArray: false),
            },
            UnknownFreeCount: 0);

        var text = new ConsoleReporter().Format(report);

        Assert.Contains("4", text);
        Assert.Contains("0x1", text);
        Assert.Contains("main.cpp", text);
        Assert.Contains("7", text);
        Assert.DoesNotContain("{leak.", text);
    }
}
```

### 6.2 `CliApp.cs`

```csharp
using LeakDetector.Core.Model;

namespace LeakDetector.CLI;

public static class CliApp
{
    public static int Run(
        string[] args,
        Func<string, AnalysisReport> analyzeFile,
        TextWriter stdout,
        TextWriter stderr)
    {
        if (args.Length != 2 ||
            !string.Equals(args[0], "analyze", StringComparison.OrdinalIgnoreCase))
        {
            stderr.WriteLine("Usage: LeakDetector.CLI analyze <path-to.jsonl>");
            return 3;
        }

        var path = args[1];
        if (!File.Exists(path))
        {
            stdout.WriteLine($"File {path} does not exist");
            return 2;
        }

        try
        {
            var report = analyzeFile(path);
            new LeakDetector.Reporters.ConsoleReporter().Write(report, stdout);
            return report.LeakCount > 0 ? 1 : 0;
        }
        catch (Exception e)
        {
            stderr.WriteLine(e.Message);
            return 4;
        }
    }
}
```

### 6.4 `CliAppTests.cs`

```csharp
using LeakDetector.CLI;
using LeakDetector.Core.Model;

namespace LeakDetector.Tests;

public class CliAppTests
{
    private static AnalysisReport EmptyReport() =>
        new(Array.Empty<LeakEntry>(), 0);

    private static AnalysisReport OneLeakReport() =>
        new(new[] { new LeakEntry("0x1", 4, "main.cpp", 7, false) }, 0);

    [Fact]
    public void Run_BadUsage_Returns3()
    {
        var code = CliApp.Run(
            new[] { "analyzer", "x.jsonl" },
            _ => EmptyReport(),
            TextWriter.Null,
            TextWriter.Null);

        Assert.Equal(3, code);
    }

    [Fact]
    public void Run_MissingFile_Returns2()
    {
        var code = CliApp.Run(
            new[] { "analyze", Path.Combine(Path.GetTempPath(), Guid.NewGuid() + ".jsonl") },
            _ => EmptyReport(),
            TextWriter.Null,
            TextWriter.Null);

        Assert.Equal(2, code);
    }

    [Fact]
    public void Run_NoLeaks_Returns0()
    {
        var tmp = Path.GetTempFileName();
        try
        {
            var code = CliApp.Run(
                new[] { "analyze", tmp },
                _ => EmptyReport(),
                TextWriter.Null,
                TextWriter.Null);

            Assert.Equal(0, code);
        }
        finally
        {
            File.Delete(tmp);
        }
    }

    [Fact]
    public void Run_HasLeaks_Returns1()
    {
        var tmp = Path.GetTempFileName();
        try
        {
            var code = CliApp.Run(
                new[] { "analyze", tmp },
                _ => OneLeakReport(),
                TextWriter.Null,
                TextWriter.Null);

            Assert.Equal(1, code);
        }
        finally
        {
            File.Delete(tmp);
        }
    }
}
```
