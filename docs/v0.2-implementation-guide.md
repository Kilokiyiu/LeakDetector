## 1. v0.2 要达成什么

| v0.1 | v0.2 |
|------|------|
| C++ 在控制台直接 `ReportLeaks()` | C++ **写 JSONL 事件日志** |
| 无 C# | C# **读日志 → 配对 → 出报告** |

**闭环**：

```
C++ 程序 (new/delete)
    ↓ 写文件
leak_log.jsonl
    ↓ C# 解析 + 分析
dotnet run -- analyze leak_log.jsonl
    ↓
与 v0.1 控制台报告一致的泄漏结论
```

**v0.2 不做**：调用栈、泄漏分类（Possibly Lost）、JsonReporter/CI、malloc 拦截。

## 3. JSONL 日志格式（你要实现的契约）

一行一条 JSON，UTF-8，`\n` 换行。每条有单调递增的 `id`（从 1 开始）。

### 3.1 `alloc` — 分配时写

在 `leak_detector_record_alloc`（或等价路径）写入：

```json
{"event":"alloc","id":1,"ptr":"0x000001A2B3C4D5E0","size":4,"kind":"new","file":"main.cpp","line":7}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event` | string | 固定 `"alloc"` |
| `id` | number | 递增 |
| `ptr` | string | `%p` 格式即可，C# 当字符串键用 |
| `size` | number | 字节数 |
| `kind` | string | `"new"` 或 `"new[]"` |
| `file` | string | `__FILE__`，JSON 内转义 `\` |
| `line` | number | `__LINE__` |

### 3.2 `free` — 释放时写

在 `delete` 成功从 map 移除记录后写入：

```json
{"event":"free","id":2,"ptr":"0x000001A2B3C4D5E0","kind":"delete"}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event` | string | 固定 `"free"` |
| `id` | number | 递增 |
| `ptr` | string | 与 alloc 相同 |
| `kind` | string | `"delete"` 或 `"delete[]"` |

v0.2 可省略 `file`/`line`（delete 侧暂未传源位置）。

### 3.3 `summary` — `ReportLeaks()` 末尾写

```json
{"event":"summary","id":3,"leak_count":1,"total_leak_bytes":4}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event` | string | 固定 `"summary"` |
| `leak_count` | number | 当前仍未释放块数 |
| `total_leak_bytes` | number | 上述块 size 之和 |

C# **以 replay alloc/free 的结果为准**；`summary` 用于交叉核对（可选测试）。

### 3.4 环境变量

| 变量 | 值 | 作用 |
|------|-----|------|
| `LEAK_DETECTOR_LOG_PATH` | 文件路径，如 `leak_log.jsonl` | 设置后才写 JSONL |
| `LEAK_DETECTOR_MODE` | `console`（默认）/ `log` / `both` | 控制 `ReportLeaks` 是否仍打控制台 |

建议行为：

- 未设置 `LEAK_DETECTOR_LOG_PATH` → 行为与 v0.1 完全相同，不写文件
- `MODE=log` → 只写文件，控制台不输出泄漏报告
- `MODE=both` → 文件 + 控制台

### 3.5 C++ 实现注意点

- 每写一行 `fflush`，防止崩溃丢日志
- Windows 路径 `\` 在 JSON 字符串里写成 `\\`
- 日志写入不要触发全局 `operator delete` 递归（继续用 `malloc` allocator 的 map，与 v0.1 相同）
- `leak_detector.cpp` 顶部 `#undef new` 后再实现写文件逻辑

## 8. 常见问题

| 问题 | 方向 |
|------|------|
| JSON 里路径乱码或解析失败 | C++ 侧转义 `\`；文件 UTF-8 |
| C# 报 unknown free 很多 | ptr 字符串大小写/格式不一致，统一 `%p` |
| 加了日志后 `delete` 又 abort | 写日志不要用 `std::cout`/触发 STL 分配；别在持锁时递归进 `new` |
| C++ 与 C# 泄漏条数不一致 | 对比 jsonl 是否每条 alloc 都有对应 free；summary 仅作参考 |

### 10.1 C++：`leak_detector.cpp` 追加部分

在现有 `namespace { ... }` **内部**、`g_mutex` 声明之后追加日志状态与辅助函数；再按标注修改 `leak_detector_delete`、`leak_detector_record_alloc`、`ReportLeaks`。

**新增：头文件与日志基础设施**（放在 `namespace {` 内、`g_mutex` 之后）：

```cpp
#include <cstdio>   // 若文件顶部已有可省略

enum class OutputMode { Console, Log, Both };

FILE*       g_logFile      = nullptr;
const char* g_logPath      = nullptr;
unsigned    g_nextEventId  = 1;
bool        g_logInitDone  = false;

OutputMode get_output_mode() {
    const char* mode = std::getenv("LEAK_DETECTOR_MODE");
    if (!mode || mode[0] == '\0') {
        return OutputMode::Console;
    }
    if (std::strcmp(mode, "log") == 0) {
        return OutputMode::Log;
    }
    if (std::strcmp(mode, "both") == 0) {
        return OutputMode::Both;
    }
    return OutputMode::Console;
}

bool logging_enabled() {
    return get_output_mode() != OutputMode::Console || g_logPath != nullptr;
}

bool console_report_enabled() {
    OutputMode mode = get_output_mode();
    return mode == OutputMode::Console || mode == OutputMode::Both;
}

void ensure_log_file_open() {
    if (g_logInitDone) {
        return;
    }
    g_logInitDone = true;
    g_logPath = std::getenv("LEAK_DETECTOR_LOG_PATH");
    if (!g_logPath || g_logPath[0] == '\0') {
        return;
    }
    g_logFile = std::fopen(g_logPath, "wb");
}

void json_write_string(std::FILE* out, const char* s) {
    std::fputc('"', out);
    if (!s) {
        std::fputc('"', out);
        return;
    }
    for (const char* p = s; *p; ++p) {
        if (*p == '\\' || *p == '"') {
            std::fputc('\\', out);
        }
        std::fputc(*p, out);
    }
    std::fputc('"', out);
}

void log_alloc_event(void* ptr, std::size_t size, const char* file, int line, bool isArray) {
    ensure_log_file_open();
    if (!g_logFile) {
        return;
    }
    std::fprintf(g_logFile,
        "{\"event\":\"alloc\",\"id\":%u,\"ptr\":\"%p\",\"size\":%zu,\"kind\":\"%s\",",
        g_nextEventId++,
        ptr,
        size,
        isArray ? "new[]" : "new");
    std::fputs("\"file\":", g_logFile);
    json_write_string(g_logFile, file);
    std::fprintf(g_logFile, ",\"line\":%d}\n", line);
    std::fflush(g_logFile);
}

void log_free_event(void* ptr, bool isArray) {
    ensure_log_file_open();
    if (!g_logFile) {
        return;
    }
    std::fprintf(g_logFile,
        "{\"event\":\"free\",\"id\":%u,\"ptr\":\"%p\",\"kind\":\"%s\"}\n",
        g_nextEventId++,
        ptr,
        isArray ? "delete[]" : "delete");
    std::fflush(g_logFile);
}

void log_summary_event(std::size_t leakCount, std::size_t totalBytes) {
    ensure_log_file_open();
    if (!g_logFile) {
        return;
    }
    std::fprintf(g_logFile,
        "{\"event\":\"summary\",\"id\":%u,\"leak_count\":%zu,\"total_leak_bytes\":%zu}\n",
        g_nextEventId++,
        leakCount,
        totalBytes);
    std::fflush(g_logFile);
}
```

**修改：`leak_detector_delete`**（在 `erase` **之前**写 `free` 事件，并从记录里取 `isArray`）：

```cpp
void leak_detector_delete(void* ptr) noexcept {
    if (!ptr) {
        return;
    }
    bool tracked = false;
    bool isArray = false;
    {
        std::lock_guard<std::mutex> lock(g_mutex);
        const auto it = g_allocMap.find(ptr);
        if (it != g_allocMap.end()) {
            isArray = it->second.isArray;
            log_free_event(ptr, isArray);   // erase 之前
            g_allocMap.erase(it);
            tracked = true;
        }
    }
    if (tracked) {
        deallocate_raw(ptr);
    } else {
        deallocate_untracked(ptr);
    }
}
```

**修改：`leak_detector_record_alloc`**（map 写入后追加 `alloc` 事件）：

```cpp
void leak_detector_record_alloc(void* ptr, std::size_t size, const char* file, int line, bool isArray) {
    if (!ptr) {
        return;
    }
    std::lock_guard<std::mutex> lock(g_mutex);
    g_allocMap[ptr] = {size, file, line, isArray};
    log_alloc_event(ptr, size, file, line, isArray);
}
```

**修改：`ReportLeaks`**（先写 `summary`，再按 `MODE` 决定是否打控制台）：

```cpp
void ReportLeaks() {
    std::lock_guard<std::mutex> lock(g_mutex);

    std::size_t totalBytes = 0;
    for (const auto& entry : g_allocMap) {
        totalBytes += entry.second.size;
    }
    log_summary_event(g_allocMap.size(), totalBytes);

    if (!console_report_enabled()) {
        return;
    }

    if (g_allocMap.empty()) {
        std::printf("[LeakDetector] No leaks detected.\n");
        return;
    }

    std::printf("[LeakDetector] FOUND %zu LEAK(S):\n", g_allocMap.size());
    for (const auto& entry : g_allocMap) {
        const void* ptr = entry.first;
        const AllocRecord& rec = entry.second;
        std::printf("  LEAK: %zu bytes at %p  [%s:%d]", rec.size, ptr, rec.file, rec.line);
        if (rec.isArray) {
            std::printf(" [array]");
        }
        std::printf("\n");
    }
}
```

`namespace` 外还需 `#include <cstring>`（`std::strcmp`）。

**`Services/SimpleLeakAnalyzer.cs`**：

```csharp
using LeakDetector.Core.Models;

namespace LeakDetector.Core.Services;

public sealed class SimpleLeakAnalyzer
{
    public AnalysisReport Analyze(IEnumerable<MemoryEvent> events)
    {
        var ordered = events.OrderBy(e => e.Id).ToList();
        var live = new Dictionary<string, LeakEntry>();
        var unknownFreeCount = 0;

        foreach (var ev in ordered)
        {
            switch (ev)
            {
                case AllocEvent alloc:
                    live[alloc.Ptr] = new LeakEntry(
                        alloc.Ptr,
                        alloc.Size,
                        alloc.File,
                        alloc.Line,
                        alloc.IsArray);
                    break;

                case FreeEvent free:
                    if (!live.Remove(free.Ptr))
                    {
                        unknownFreeCount++;
                    }
                    break;

                case SummaryEvent summary:
                    // v0.2：以 replay 为准；调试时可断言：
                    // System.Diagnostics.Debug.Assert(summary.LeakCount == live.Count);
                    break;
            }
        }

        return new AnalysisReport(live.Values.ToList(), unknownFreeCount);
    }
}
```

### 10.4 C# Parsers

**`JsonlEventParser.cs`**：

```csharp
using System.Text.Json;
using LeakDetector.Core.Models;

namespace LeakDetector.Parsers;

public static class JsonlEventParser
{
    public static IReadOnlyList<MemoryEvent> ParseFile(string path)
    {
        if (!File.Exists(path))
        {
            throw new FileNotFoundException("JSONL log file not found.", path);
        }

        var events = new List<MemoryEvent>();
        foreach (var line in File.ReadLines(path))
        {
            if (string.IsNullOrWhiteSpace(line))
            {
                continue;
            }
            events.Add(ParseLine(line));
        }
        return events;
    }

    private static MemoryEvent ParseLine(string line)
    {
        using var doc = JsonDocument.Parse(line);
        var root = doc.RootElement;

        var id = root.GetProperty("id").GetInt32();
        var eventType = root.GetProperty("event").GetString()
            ?? throw new JsonException("Missing 'event' field.");

        return eventType switch
        {
            "alloc" => new AllocEvent(
                id,
                root.GetProperty("ptr").GetString()!,
                root.GetProperty("size").GetUInt64(),
                root.GetProperty("kind").GetString()!,
                root.GetProperty("file").GetString()!,
                root.GetProperty("line").GetInt32()),

            "free" => new FreeEvent(
                id,
                root.GetProperty("ptr").GetString()!,
                root.GetProperty("kind").GetString()!),

            "summary" => new SummaryEvent(
                id,
                root.GetProperty("leak_count").GetInt32(),
                root.GetProperty("total_leak_bytes").GetUInt64()),

            _ => throw new JsonException($"Unknown event type: {eventType}")
        };
    }
}
```

### 10.6 C# Reporters

```csharp
using System.Text;
using LeakDetector.Core.Models;

namespace LeakDetector.Reporters;

public sealed class ConsoleReporter
{
    public void Write(AnalysisReport report, TextWriter output)
    {
        if (report.LeakCount == 0)
        {
            output.WriteLine("[LeakDetector] No leaks detected.");
            return;
        }

        output.WriteLine($"[LeakDetector] FOUND {report.LeakCount} LEAK(S):");
        foreach (var leak in report.Leaks)
        {
            output.Write($"  LEAK: {leak.Size} bytes at {leak.Ptr}  [{leak.File}:{leak.Line}]");
            if (leak.IsArray)
            {
                output.Write(" [array]");
            }
            output.WriteLine();
        }
    }

    public string Format(AnalysisReport report)
    {
        var sb = new StringBuilder();
        using var writer = new StringWriter(sb);
        Write(report, writer);
        return sb.ToString();
    }
}
```

```csharp
using LeakDetector.Analyzers;
using LeakDetector.Reporters;

namespace LeakDetector.CLI;

internal static class Program
{
    static int Main(string[] args)
    {
        if (args.Length != 2 || !string.Equals(args[0], "analyze", StringComparison.OrdinalIgnoreCase))
        {
            Console.Error.WriteLine("Usage: LeakDetector.CLI analyze <path-to.jsonl>");
            return 1;
        }

        var path = args[1];
        if (!File.Exists(path))
        {
            Console.Error.WriteLine($"File not found: {path}");
            return 2;
        }

        try
        {
            var report = new LeakAnalysisService().AnalyzeLogFile(path);
            new ConsoleReporter().Write(report, Console.Out);
            return report.LeakCount > 0 ? 3 : 0;   // 可选：有泄漏时非 0
        }
        catch (Exception ex)
        {
            Console.Error.WriteLine(ex.Message);
            return 4;
        }
    }
}
```
